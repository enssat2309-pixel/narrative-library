# Résultats du tour 1

## Accord entre les deux bots (63 segments)

| Mesure | Alpha de Krippendorff | Accord brut |
|---|---|---|
| Code principal | 0,97 | 61/63 |
| Domaine | 0,98 | 62/63 |
| Temporalité | 0,92 | 60/63 |
| Fonction, durabilité, gouvernance | 1,00 | 63/63 |

Par type de document (code principal) : KID 1,00 ; factsheets 1,00 ; rapports 1,00 ; prospectus 0,92 ; fiches locales 0,00 (2 segments).

Désaccords : L1-010 (risque de coûts de transaction, D5 / F1) et L1-015 (missions du dépositaire, A5 / A2).

**Réserve.** Les deux codeurs sont des modèles de la même famille : même code alternatif sur 27 segments, mêmes remarques, parfois la même justification. L'alpha mesure surtout leur constance commune.

## Failles du codebook signalées par les deux codeurs

1. Segments mixtes : la règle « le plus de texte » dépend d'écarts minimes, deux secondaires ne suffisent pas.
2. Explications des tableaux du KID : sujet (F2, E1) ou méthode (J5).
3. Contacts (J2, A2, J3) ; « pas une offre » (J1 ou A3).
4. Indice : frontière B1/B4 ; écart de suivi sans code.
5. Contenus sans code : collatéral, délégation du dépositaire, risque lié à la stratégie, clauses de licence d'indice.
6. Incohérence entre la règle 8 et la définition du marqueur gouvernance.

## Revue humaine guidée (19 novembre 2026)

15 segments tirés au hasard (graine « 2026-controle-humain ») parmi ceux où les bots sont d'accord.

- Série 1 (5 segments) : réponses données au niveau du domaine seulement, la liste détaillée des codes n'ayant pas été fournie à l'arbitre. Retirée de la mesure ; gardée comme indice qualitatif (ESG dans la méthode d'un indice, définitions de glossaire, segment mêlant méthode de calcul et frais).
- Séries 2 et 3 (10 segments, au niveau du code) : premier choix de l'arbitre identique aux bots dans 5 cas ; code des bots parmi les options de l'arbitre dans 8 cas. Écarts nets : ERISA (bots J4, arbitre G3) et reste de graphique (bots I1, arbitre hors périmètre).
