# D-016 – Unité de codage

- **Date :** 2026-11-24
- **Statut :** Validé
- **Décideur :** arbitre du projet (sur proposition de Claude)

## Décision

Découpage mécanique des segments tirés (tableaux par ligne, texte par phrase). Chaque unité reçoit au plus 2 domaines et 2 codes par domaine, dans un ordre (le premier est le code principal). Une étiquette n'est ajoutée que si l'aspect est réellement énoncé. Mesure à trois niveaux (domaine, code principal, ensemble des étiquettes). Marqueurs durabilité et gouvernance supprimés ; temporalité et fonction gardées pour le code principal.
