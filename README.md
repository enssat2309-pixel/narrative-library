## Conventions communes proposées

- Langue : français.
- Noms de fichiers et dossiers : minuscules, tirets, sans accents ni espaces (`feuille-de-route.md`), dates au format AAAA-MM-JJ.
- Les fichiers lourds (PDF, archives, corpus complets) ne sont pas versionnés : ils sont rangés dans Dropbox, dossier « Narratives Library », et référencés ici par leur chemin et leur empreinte sha256.
- Toute modification passe par une pull request relue.
